# exp_3 — 指标表：Precision / F1 / Recall / PairBrier / TruthAcc / IDAcc / IDECE

数据链路（回答"是不是 tool → VI → truth"）：

```
tool_task{4,5}_property.xlsx        检测 + 工具上报的属性      ← 引擎输入
        │
        ▼  D-S 配对 → 共享身份 VI → cascade        （每折用训练折重拟合的 θ）
        │
predictions.jsonl                    VI 判定结果
        │
        ▼  只在这里读标注
truth_task{4,5}_property.xlsx        instances + identities    ← 评测标签
```

推理阶段不读 truth；评测阶段才按 IoU≥0.5 建 tool→truth 实例桥，再做对象级贪心匹配。

## 定义

| 指标 | 定义 |
|---|---|
| Precision / Recall / F1 | 对象级 TP/FP/FN：预测对象的成员检测（经实例桥）解析到同一标注对象即 TP；贪心按成员重合度取最大。口径同 `property_metrics.identity_metrics` |
| PairBrier↓ | 只统计**跨视角配对声明**（同时有两名成员的预测对象）：`y=1` 解析到标注的双视角对象，否则 0；`p` 取对象后验 `vi_p_class`。Brier = mean((p−y)²) |
| TruthAcc. | 在**解析到标注对象**的预测里，VI 判定类别 == 标注类别的比例（未检出不计入） |
| IDAcc. | 跨视角身份准确率：仓库 `G5_identity.composite.association_accuracy`（confirmed 双视角对 vs over-merge 的 F1） |
| IDECE↓ | 与 PairBrier 同一批配对声明的期望校准误差：10 等宽分箱，`Σ (n_b/N)·|acc_b − conf_b|` |

> P/R/F1 与 IDAcc 在三臂里**必然相同**：θ 改变的是概率，不是判定的对象/配对。能区分三臂的只有 PairBrier 与 IDECE。

## 敏感性：PairBrier/IDECE 依赖置信度字段

同一批配对声明，换 `p` 的来源（`--confidence`）：

| 字段 | match refit / shipped / noctx (Brier) | time refit / shipped / noctx (Brier) |
|---|---|---|
| `vi_p_class`（主表） | **0.310 / 0.364 / 0.410** | **0.418 / 0.423 / 0.425** |
| `vi_association` | 0.291 / 0.349 / 0.201 | 0.464 / 0.473 / 0.370 |
| `score`（cascade blend） | 0.218 / 0.240 / 0.258 | 0.246 / 0.247 / 0.248 |
| `betp`（D-S 阶段，θ 无关） | 0.173 / 0.173 / 0.173 | 0.237 / 0.237 / 0.238 |

`betp` 三臂完全相同，正好证明链路没串（θ 只作用在 VI 阶段）。

**结论对字段敏感**：只有 `vi_p_class` / `score` 下 θ 改善 Brier；用 `vi_association`（配对质量）反而变差。
论文若要报 PairBrier，必须**先把"p 是什么"写死**，否则可复现性存疑。

## 怎么读

1. **判定结果三臂几乎不变**（P/R/F1、IDAcc、TruthAcc 全同），θ 影响的是**置信度的校准**：
   match 的 PairBrier 0.410→0.310、IDECE 0.470→0.387（pooled）。
2. time 族提升很小（0.4245→0.4176），且 CI 很宽 —— 与五折结果一致：θ 的收益集中在 match。
3. match 的 PairBrier 只有 **97 个配对声明**（5 折合计），单折约 19 个，CI ±0.05，结论强度有限。
4. TruthAcc 这里按"已解析到标注的对象"算（match 0.9878）；若把漏检算错（论文 G4 口径），
   match 是 **0.5739**、time 是 **0.7603** —— 两个数不能混用。
